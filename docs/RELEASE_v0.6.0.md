# BOM管理系统 v0.6.0

本次发布汇总仓库实际标签 **V0.5.1** 至 **v0.6.0** 的变更。下文描述最终生效的行为，期间被后续方案取代的临时实现不作为独立功能重复列出。

## 新增功能

### SKU与镜像管理
- SKU支持独立镜像版本，已有及新建BOM默认镜像版本100；支持复制BOM和修改镜像版本，区分SKU版本与镜像版本。
- SKU清单新增镜像版本列、筛选、只显示最新BOM开关；支持按编码、名称和修改时间排序，整行选择。
- 支持逐镜像编辑多行变更描述；非空描述的镜像号加粗，悬停显示描述。
- 统计改为“共计n个SKU，m个BOM”，同编码不同镜像仅计为一个SKU。
- SKU右键可启动BOM对比并以该SKU镜像为基准。

### BOM编辑与版本策略
- 支持筛选选择替换物料，继承原关系的数量、位置、备注及替代料；替换前列出相同物料的所有出现位置，可勾选同步替换。
- 替代料支持切换为主物料，原主料变为替代料，其他替代料及可编辑属性保留。
- 支持选择同基础编码的其他物料版本并替换子BOM；目标无结构时可选择复制原子BOM。
- 待删除物料支持右键取消删除；BOM树和对比窗口均可右键直接编辑物料属性。
- 镜像保存整棵BOM树的独立关系、替代料、属性及历史。历史镜像不随其他最新镜像自动改写。
- 非SKU父项只被当前镜像使用时，可直接调整子BOM；其他SKU或同SKU其他镜像也引用时，按规则检查父项升版。SKU本身版本仍由用户手动控制。
- 保存最新镜像中被其他SKU最新镜像使用的子BOM前，显示变更及受影响BOM清单供勾选：全选则同版本同步；部分或全部不选则要求父项新版本，只有当前及勾选的BOM切换新版本。
- 升版提示显示子料新增/移除差异、其他引用SKU与镜像，隐藏相同子料；长清单支持滚动。
- 新增、粘贴、替换和版本更新读取当前有效物料信息及子BOM，先进入编辑缓存，保存后写库。

### BOM对比
- 新增左右BOM对比，可比较不同SKU及同SKU不同镜像；非模态窗口允许同时编辑，已启动的对比随编辑更新。
- 可载入本地XLSX/XLS作为临时外部BOM，选择sheet并映射各列、增加替代料映射组，无需先导入物料库，不写入数据库。
- 状态独立显示，支持新增、删除、修改、换料及主替料交换；物料编码与版本作为整体比较和显示。
- 同分支相同编码物料、相似名称换料自动对齐；父项换料后继续细比子项，避免整树误判为删除/新增。
- 比较忽略单纯位置序号变化；显示对齐后的层级序号，比较排序不改变原BOM顺序。
- 差异行淡黄色提示，具体差异文字按新增/删除/修改着色加粗；料号差异整段高亮。
- 左右整行选择联动、对应行同步滚动；滚动时冻结序号、父料号、料号和名称；支持全屏、自动列宽和换行，默认最大列宽20字符。
- 增加“只显示变更差异”；打开窗口默认不对比，点击对比后启动。
- 可从对比行打开对应BOM并定位物料，也可直接编辑物料；候选排序跟随SKU清单。

### 物料库、采购BOM与查找
- 物料库可按SKU显示递归累计总用量，无此料显示NA；支持勾选显示哪些SKU列，默认不选并记忆选择。
- SKU用量表头分两行展示编码/名称，按编码设置列宽，悬停显示完整标题，超长标题滚动显示；冻结物料名称及左侧列。
- 用量单元格区分有料与NA底色，呆滞料红色保持更高优先级。
- 新增采购BOM导出，递归统计所有下阶物料总量，包含物料等级、M/P、制造商、MPN及动态替代料字段，采用格式化Excel输出。
- BOM编辑器新增物料查找与定位，物料库和BOM编辑器支持Ctrl+F；新建SKU和物料支持各窗口内Ctrl+N。

## 软件优化

### 导入、选择与配置
- 物料导入新增可选“物料等级”和“M/P”映射及模板列；未映射采用默认值。
- 物料单位大小写不敏感匹配，并按配置的标准写法归一化。
- 分别记忆物料/BOM导入映射；新文件找不到原列时恢复未选择。必选项以星号标识，已选择映射浅绿色显示。
- BOM导入检查已有子BOM差异，可停止导入、使用系统结构或使用导入结构。
- 物料选择支持输入筛选、回车选中首个候选；已有预选或高亮候选时回车直接确认，包含小键盘回车。
- 数据库及导入路径使用跨平台相对路径；改善Windows与Linux共享配置、SMB挂载路径和上次导入目录记忆。
- 外部对比BOM记忆完整文件路径，文件仍在时自动定位，否则回退桌面。

### 界面与性能
- 同类窗口即时复用最近调整的尺寸与位置；配置开关支持恢复默认窗口布局。
- 优化SKU菜单排序与底部版本号居中布局，移除底部开发者字符串；增加全局按钮悬停反馈。
- BOM信息支持选择复制和自动换行；优化双栏默认宽度。
- 新增同级物料紧邻当前物料下方；编辑、替换、交换、删除时保持可见位置，选中物料不可见时才滚动居中。
- 数量按实际有效精度显示，无小数则显示整数，去除末尾零。
- 保存显示进度，减少重复关系写入、批量读取替代料及计算联动范围；替换候选批量检查循环限制，改善大物料库响应。
- 修复对比点击后的延迟跳动，精简全屏按钮布局。

### 数据库维护
- 最新镜像与公共子BOM同步在事务内处理，包含关系、替代料、日志及时间；失败整体回滚，提交后才通知窗口。
- 删除后清理不可达关系、悬空替代料、旧BOM缓存和无效捕获数据；保护有效SKU、历史镜像、物料主资料及变更记录。
- 新增引用/替代关系索引，批量查询，关闭时执行轻量PRAGMA optimize。
- 打开数据库时检查孤立结构，清理前自动备份；实际删除结构后尝试VACUUM回收主数据库空间，记录清理及压缩结果。

## Bug修复清单

- 修复Deepin文件管理器启动AppImage与终端启动行为不一致、长路径单实例服务名问题；撤回临时桌面快捷方式方案。
- 改善SMB路径下数据库创建/打开失败、database is locked及只读恢复处理，并修正AppImage运行时提取判断。
- 修复BOM导入SMB路径不记忆、配置路径在Windows/Linux间不可移植的问题。
- 修复删除被其他BOM引用的SKU时误删被引用结构。
- 修复BOM保存后SKU修改时间未更新及联动SKU时间遗漏；时间显示按本机时间处理，秒保留两位小数。
- 修复编辑SKU变更描述后焦点和滚动位置跳动，关闭弹窗后回到对应镜像。
- 修复普通物料替换/版本更新时遗漏子BOM复制提示，以及镜像中新建下阶后物料库结构标记不正确。
- 修复替换、主替料交换、删除后的树位置跳动及待删除焦点丢失。
- 修复镜像旧捕获缓存导致新增或替换后取到过期子BOM；明确空结构不恢复旧子项。
- 修复原样加入公共子BOM被误判为公共结构修改，误弹同步或升版提示。
- 修复物料只在105等镜像中存在子BOM、公共目录已清理时错误显示无BOM结构。检测所有实际包含镜像，每SKU取最高包含镜像，跨SKU再按保存时间选取；标记、导出、编辑定位和子BOM取数保持一致。
- 修复公共目录缓存被误当独立BOM，反查错误显示“未包含在SKU中”；实际引用从全部SKU镜像可达结构读取，并补齐替代料引用。
- 修复清理和联动过程可能产生的孤立关系、替代关系和缓存残留，增加备份与完整性回归。

- 修复Windows文件URI选择数据库时盘符前导斜线处理，并统一短路径/长路径的相对配置存储。
- 优化大量候选物料的首次弹窗性能，避免重复构建候选模型及逐项计算下拉框宽度。

## 升级与数据说明

- 升级前请保存编辑内容并关闭旧程序，保留原数据库和config.ini。新程序通过迁移自动创建必要的数据表。
- 涉及存储迁移和孤立数据清理时，会在数据库旁生成 `.pre-whole-tree-*`、`.pre-latest-catalog-*` 或 `.pre-orphan-cleanup-*` 备份，目录需有写权限及足够空间。
- 首次统一既有最新镜像结构时，按最近保存的最新镜像确定公共结构；之后保存按勾选确认执行。旧历史镜像保留；以前已被覆盖的数据无法凭空重建，可从旧备份恢复。
- VACUUM缩小的是主数据库文件；安全备份继续占用独立空间。压缩受锁影响失败时，清理结果仍会保留并记录原因。

## 发布文件与验证

- Linux x86_64 AppImage及对应SHA-256校验文件，面向deepin 25 / Ubuntu 24.04及以上同架构环境。下载后赋予执行权限运行。
- GitHub Actions从同一发布标签原生构建Linux AppImage和Windows x64单文件EXE，验证成功后随Release上传；Windows目标系统为Windows 10/11。附件均为本标签新构建，不使用旧版文件改名。
- 发布流程执行完整单元/UI回归、需求审计、Python语法编译及AppImage自检。自检覆盖SQLite、Excel、主窗口/物料库/BOM、镜像隔离、最新同步确认和历史保留；无界面自检不等同于所有目标操作系统的人工桌面测试。
