## 数据库需求变更审计（2026-09-24）

用户已将后端从 MySQL 变更为 SQLite。本次审计确认：

- `src/database/database.py` 仅使用 Python 标准库 `sqlite3`。
- `src/main.py` 启动时仅创建 SQLite 数据库连接。
- `requirements.txt` 已移除 PyMySQL。
- 默认数据库为软件目录下的 `bom.db`，配置由 `config.ini` 的 `database.path` 指定。
- 数据库相关测试使用临时 SQLite 文件并已通过。

该变更覆盖原需求 99~107 的后端实现解释，后续验收以 SQLite 文件可用性、结构校验和恢复流程为准。
