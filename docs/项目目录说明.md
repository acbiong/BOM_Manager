# 项目目录说明

- `src/`：Python/PyQt源代码，按启动、配置、数据库、物料、SKU、BOM、Excel、界面、日志模块拆分。
- `tools/`：测试、构建、发布、可移植性检查和自动打包脚本。
- `package/`：最终独立运行包（AppImage及校验文件）和运行时数据库配置，不存放脚本。
- `.tmp/`：编译、PyInstaller、AppImage生成的临时目录（已加入Git忽略规则，不作为发布内容）。
- `docs/`：软件开发规格书、接口文件、AI编程规范、许可证、使用说明。
- `tests/`：单元、集成、系统测试代码及测试数据。
- `test_reports/`：代码审查、测试执行和缺陷报告。
- `README.md`：构建、运行、打包、版本和后续AI协作说明。
